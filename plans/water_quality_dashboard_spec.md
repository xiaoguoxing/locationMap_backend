# Water Quality Map Dashboard Specification

## Overview
A responsive, single-page web application that displays interactive water quality maps generated by the existing Python mapping pipeline. The dashboard scans the `maps/output/` directory, parses map filenames, and presents an intuitive interface for browsing water quality data.

## Requirements Summary

| Requirement | Implementation Approach |
|-------------|----------------------|
| 1 | Display latest dates as selection range - Parse YYYY-MM-DD from filenames, sort descending, populate dropdown |

## Technical Specifications

### 1. File Naming Convention Analysis

**Current Pattern:**
```
{parameter}_{date_from}_{date_to}_{timestamp}_map.html
```

**Examples:**
- `cl2_free_1_2025-10-19_2025-11-01_20260327_184448_map.html`
- `ecoli_2025-10-19_2025-11-01_20260327_180351_map.html`
- `turby_2025-10-19_2025-11-01_20260327_180351_map.html`

**Legacy Pattern (no date ranges):**
```
{parameter}_{timestamp}_map.html
```

**Examples:**
- `cl2_free_1_20260327_120219_map.html`

**Fields:**
- **parameter**: `cl2_free_1`, `ecoli`, `turby`
- **date_from**: YYYY-MM-DD format
- **date_to**: YYYY-MM-DD format
- **timestamp**: YYYYMMDD_HHMMSS format
- **extension**: `_map.html`

### 2. Supported Water Quality Parameters

| Parameter Code | Display Name | Unit | File Pattern |
|---------------|-------------|------|--------------|
| `cl2_free_1` | Free Chlorine | mg/L | cl2_free_1* |
| `ecoli` | E. coli | CFU/100mL | ecoli* |
| `turby` | Turbidity | NTU | turby* |

### 3. Backend API (Flask)

#### Base URL
```
http://localhost:5000
```

#### Endpoints

##### GET /api/maps
Returns a JSON list of all available maps with parsed metadata.

**Response Format:**
```json
{
  "success": true,
  "data": [
    {
      "filename": "cl2_free_1_2025-10-19_2025-11-01_20260327_184448_map.html",
      "parameter": "cl2_free_1",
      "display_name": "Free Chlorine",
      "unit": "mg/L",
      "date_from": "2025-10-19",
      "date_to": "2025-11-01",
      "date_range": "2025-10-19 to 2025-11-01",
      "timestamp": "20260327_184448",
      "url": "/maps/output/cl2_free_1_2025-10-19_2025-11-01_20260327_184448_map.html"
    },
    ...
  ],
  "summary": {
    "total_maps": 27,
    "parameters": {
      "cl2_free_1": 3,
      "ecoli": 12,
      "turby": 12
    },
    "date_range": {
      "earliest": "2025-10-19",
      "latest": "2025-11-07"
    }
  }
}
```

##### GET /maps/output/{filename}
Serves the actual HTML map file (static file serving).

#### 4.2 UI Components

**Header:**
- Title: "Water Quality Map Dashboard"
- Subtitle: "Hong Kong Water Quality Monitoring"

**Parameter Selector:**
- Bootstrap 5 Form Select
- Options: Free Chlorine, E. coli, Turbidity
- Default: Free Chlorine (cl2_free_1)

**Date Range Selector:**
- Bootstrap 5 Form Select
- Dynamic options from API
- Sorted by date (newest first)
- Format: "2025-10-25 to 2025-11-07"
- Default: Latest available date range

**Map Display:**
- Responsive iframe (100% width, ~70vh height)
- Border and shadow for visual separation
- Loading indicator while fetching map

**Legend/Info Panel:**
- Current parameter info
- Unit display
- Date range display
- Last updated timestamp

#### 4.3 JavaScript Logic

**State Management:**
```javascript
const state = {
  maps: [],           // Array of map metadata
  selectedParameter: 'cl2_free_1',
  selectedDateRange: null,
  isLoading: false
};
```

**Functions:**
1. `fetchMaps()` - Call `/api/maps` endpoint
2. `parseMapsResponse(data)` - Process and cache map data
3. `populateParameterDropdown()` - Fill parameter selector
4. `populateDateRangeDropdown()` - Fill date range selector for selected parameter
5. `selectDefaultMap()` - Auto-select chlorine + latest date on load
6. `loadMap(parameter, dateRange)` - Update iframe src
7. `showLoading()` / `hideLoading()` - UI loading states
8. `handleParameterChange()` - Event handler for parameter selection
9. `handleDateRangeChange()` - Event handler for date range selection

### 5. Responsive Design Breakpoints

| Breakpoint | Container Width | Layout Changes |
|------------|-----------------|----------------|
| xs (<576px) | 100% | Stack controls vertically, smaller fonts |
| sm (≥576px) | 540px | Stack controls vertically |
| md (≥768px) | 720px | Side-by-side controls |
| lg (≥992px) | 960px | Side-by-side controls |
| xl (≥1200px) | 1140px | Side-by-side controls, larger iframe |

### 6. Zero-Downtime Integration

**Strategy:**
1. Backend reads from `maps/output/` directory at each API request
2. No in-memory caching of map list (or configurable cache TTL)
3. New maps appear immediately when pipeline generates them
4. Frontend polls or fetches fresh data on user interaction

**Pipeline Compatibility:**
- Existing `location_mapper.py` continues generating maps independently
- Dashboard reads the same output directory
- No changes required to existing pipeline
