# 18 区边界裁剪优化记录

## 问题描述

原有的 `clip_district_coastline.py` 虽然能够按 TPU 陆地轮廓裁掉 18 区的海域部分，但裁剪后的边界仍然存在明显问题：

1. **内部白色条纹**：292 个 TPU 拼接时产生的细小缝隙在地图上显示为白色条纹
2. **边界杂质**：拓扑问题导致的碎片、毛刺和细条
3. **顶点过多**：边界过于精细，文件体积大

## 优化方案

### 1. 多轮缓冲清理

采用「正向缓冲 → 负向缓冲 → 正向恢复」三步法：

```python
# 参数设置
BUFFER_DISTANCE = 0.0001      # 约 11 米，填充缝隙
NEGATIVE_BUFFER = -0.00015    # 约 16 米，移除细条和毛刺
```

**步骤**：
1. 正向缓冲 `+0.0001`：填充 TPU 之间的小缝隙
2. 负向缓冲 `-0.00015`：移除细条、毛刺和突出部分
3. 正向恢复 `+0.00015`：恢复到接近原始大小，边界更平滑

这个过程能有效消除内部的白色条纹，同时保持整体轮廓准确。

### 2. 轮廓简化

```python
SIMPLIFY_TOLERANCE = 0.0002  # 约 22 米
```

使用 Douglas-Peucker 算法简化轮廓，在保持形状的前提下大幅减少顶点数。

### 3. 碎片过滤

```python
MIN_AREA_RATIO = 0.005  # 0.5%
```

对于 MultiPolygon，只保留面积大于主多边形 0.5% 的部分，移除孤立的小碎片。

## 参数调优建议

如果发现：

- **白色条纹仍然明显**：增大 `BUFFER_DISTANCE` 和 `NEGATIVE_BUFFER` 的绝对值
- **边界过于粗糙**：减小 `SIMPLIFY_TOLERANCE`
- **小岛屿消失**：减小 `MIN_AREA_RATIO`
- **边界明显偏移**：减小所有缓冲参数

当前参数在视觉清洁度和几何准确性之间取得了较好平衡。
